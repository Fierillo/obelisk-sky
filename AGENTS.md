# AGENTS.md: Obelisk Sky

Obelisk Sky (https://sky.obelisk.ar) is a 3D floating-island village that is also a real Obelisk client. Every NIP-29 channel on the selected relay is a house; people walk to the house of the channel they post in, walk over to whoever they reply to, sit and drink mate, train in the park, join voice calls and play games. You log in with your own Nostr key; the server holds no keys and fetches nothing from relays. Everything happens in the browser.

This is the one instruction file for every agent here; `CLAUDE.md` only imports it. When the code moves, fix the sentence here in the same change.

## Stack

- **Three.js 0.180 + Vite 7 + TypeScript**, no framework for the world UI (plain DOM in `client/src/ui/`). React only for islands that re-host obelisk-dex components (login modal, chat message bodies, the channel message bar).
- **Relays:** `@nostr-wot/relay/hub` RelayHub, set up like obelisk-dex's page hub. Signers from `@nostr-wot/signers`, profiles from `@nostr-wot/data`, login widget `@nostr-wot/ui`.
- **Vitest** (+ jsdom and Testing Library for the React islands).
- **Server:** `server/index.ts` is a tiny Node HTTP server. It serves `dist/client` (the landing page at `/`, the village at `/app`; old `/?relay=` and `/?time=` links get a 302 to `/app`), `/healthz`, `/api/link-preview` (the vendored obelisk-dex OpenGraph unfurler, with its SSRF guards) and `/api/avatar` (`server/avatarProxy.ts`: a profile picture whose host sends no CORS, for the WebGL badge; same SSRF guards, raster images only, no SVG). Nothing else; never add relay access or keys to it.

## Commands

```bash
npm install
npx vite client --port 5174 --host 127.0.0.1   # dev (also: npm run dev:client)
npx tsc -p tsconfig.json                        # typecheck (vite build does NOT typecheck)
npm test                                        # vitest run
npm run build                                   # client to dist/client, server to dist/server.js
pm2 restart obelisk-sky                         # deploy: the live site serves this directory's dist on :3024
npm run vendor                                  # re-snapshot obelisk-dex src (see below), then copy-brand and make-icons
node scripts/make-icons.mjs                     # favicon.ico, icon-192/512, maskable, apple-touch from brand/sky-mark-flat.svg
node scripts/build-people.mjs                   # rebuild character assets from _dl/quaternius
node scripts/make-og.mjs <1200x630.png>         # redraw the link-preview card client/public/og.jpg (text kept in the centre square: WhatsApp crops to it; bump ?v=)
```

Deploy = `npm run build && pm2 restart obelisk-sky`, then check through the tunnel: `/`, `/app`, `/healthz`, the village's `assets/app-*.js`, and any new asset you added (`curl -I https://sky.obelisk.ar/...`). Run typecheck and the full test suite before every deploy.

## The seam with obelisk-dex

Obelisk-dex code is imported from `vendor/obelisk` as `@/...` (Vite alias and tsconfig `paths`). Modules that would reach the app's bridge, next-intl or Next routing are swapped by `SHIMS` in `client/vite.config.ts`, mirrored in `tsconfig.json` `paths` (`next-intl`, `@/i18n/navigation`, `@/hooks/session/useSession`, clipboard, blossom, `@/services/nostr-bridge`, `@/services/wot/engine`, the media library modal). `vitest.config.ts` uses the same `SHIMS`.

- Re-vendor deliberately (`npm run vendor`), never by editing files under `vendor/`. After re-vendoring, re-run typecheck and tests: shims may need new exports.
- Sky has its own mark (a white cloud with the Obelisk rising out of it, `client/public/brand/sky-mark*.svg`) and palette (`--sky`, `--cloud`, `--ink` in `styles.css`; the landing page and the loading screen, gate and brand pill use it, the in-app panels stay dark). `copy-brand.mjs` no longer copies obelisk-dex's icons; `make-icons.mjs` draws sky's.
- `scripts/copy-brand.mjs` copies `obelisk.stl`, writes the manifest (`start_url: /app`) and generates `client/src/obelisk.generated.css` from the vendored `globals.css` (Tailwind v4 `@source` globs for the components sky renders). Do not edit the generated file.
- **The channel message bar** (`chat/composer/`, mounted by `ui/chatPanel.ts` into `.chat-bar`) is obelisk-dex's composer: `SkyComposer.tsx` is its `ChatComposer` skin (reply bar, attachment menu, emoji/GIF/sticker picker, @-mention and slash pickers, scaffold, voice note, send) with a textarea (Shift+Enter is a new line) and the picker as a sheet in the panel's flow. `useSkyComposer.ts` is `useChannelComposer` with sky's data: mention candidates from `deps.people` (every channel's members and posters, people in the village), sends through `deps.send(group, text, reply, tags)` (custom emoji / sticker / voice-note tags from dex's `outgoingTags`; a failed send keeps the draft), bot commands from dex's `useBotCommands` (kind 30078 `obelisk:bot-commands:<relay>`, inserting the bot's own trigger such as `!milugar`), the operator's emoji set (kind 30030 `obelisk:emojis:<relay>`) into dex's chat store. `/play` opens sky's game table; `/zap` opens sky's zap sheet (below). Uploads use the blossom shim. Sky keeps no media favourites: `nostrActions.saveMediaFavorites` throws and `styles.css` hides the picker's favourite and "Create" controls.
- Wire formats must match obelisk-dex exactly (kind 9 tags, reactions, deletions, read-state kind 30078 `obelisk:readstate:v1`, games kind 2390, private messages and calls below).
- **Private messages and calls** (`nostr/dm.ts`, `voice/privateCall.ts`, `ui/dmPanel.ts`) speak obelisk-dex's protocols:
  - Chat is NIP-17: a kind 14 rumor gift-wrapped by `@nostr-wot/dm` to the recipient's inbox (10050, else 10002 read relays, else the group relay), plus a self-copy. The rumor id is the message id.
  - Calls are its 1:1 calls: kind 25055 control rumors (`services/call/protocol`) in expiring wraps, and the audio is its own `DmCallSession` (`services/call/session`, lazy, after `voice/node-globals`) on its default call relays.
  - Wraps are published with `authMode: 'never'`.
  - Near a connected person you're offered Message (M) / Call; the person card has both.
- **Zaps** (`wallet/`, `ui/zapSheet.ts`), as obelisk-dex sends them: `/zap [who] [amount]` (`wallet/zapCommand.ts`: the reply target, else the last other speaker; a name must fit one person) or the person card's ⚡ Zap. The wallet is a Nostr Wallet Connect link the account connects in the sheet (checked, sealed with dex's `nwc-storage`, spoken over the page hub with dex's `nwc-transport`), else WebLN for extension logins only; logging out forgets it. Paying asks the recipient's `lud16` (kept from kind 0) for an invoice with a NIP-57 zap request, then posts dex's ⚡ marker (kind 7, `amount`, `bolt11`) to the channel. Once paid, nothing may offer a retry (it would pay twice).
- **Members and presence.** `nostr/members.ts` reads a channel's 39001/39002 and the relay's ranks (obelisk-dex's operator-published `obelisk:roles:` catalog and holders, parsed by its `relay-roles-model`); `ui/memberGroups.ts` sections them like its member list. Presence (`nostr/presence.ts`): online = live in the village and active within 5 min, or posted within 15 min (obelisk-dex's window); AFK = live but idle; offline otherwise. Characters show it (a green dot, a 💤 AFK tag).
- Sky-only events:
  - kind 30078 `obelisk:avatar3d:v1`: your look (avatar v2 `{look,...}`; v1 still parses). Your own signed event is cached in localStorage (`obelisk-sky/avatar/<pk>`); on login or a relay switch `AvatarStore.syncOwn` shows it at once and publishes the same signed event to a relay that lacks it or has an older one. Others' looks are fetched as they appear (`AvatarStore.want`, asked again if the query didn't finish) and followed live (`AvatarStore.start`), so a change of body or clothes reaches everyone without a reload.
  - kind 30078 `obelisk-sky:themes:<relay>`: operator-only districts.
  - kind 30078 `obelisk-sky:activity:v1` (`nostr/activity.ts`): what you're doing live. Tags `op` start/stop, `spot`, NIP-40 `expiration` (90 s); content `{v,op,spot,kind,since}`. Kinds: the exercises (park and gym), `sit` (seats only) and `run` (track lanes only). Published 0.3 s after you sit or train, re-sent every 45 s, a stop when you get up. Two claims on one spot: the earlier `since` holds it.
  - ephemeral kind 20390 (`nostr/motion.ts`): live movement. Content `{v,t,p,mv?,run?,d?|h?,j?,e?,es?,y?,lp?}` (`y`: body yaw, or the eyes' yaw in first person; `lp`: first-person look pitch, ±0.6, tilts the remote head; standing, a 30° turn is a change worth sending) (`j: 1`: they just jumped; sent at take-off, at most every 400 ms, and replayed with the controller's jump physics; `e`: the emote they're playing while standing, `world/emotes.ts` kinds only, starting/stopping one is a change worth sending; `es`: when it began, their wall clock in ms, clamped to `t`): position plus a click's destination (`d`) or a key heading (`h`). Sent on a click, a turn, start/stop running or stopping; a correction every 2 s by keys / 4 s on a path; a 30 s heartbeat standing; never more than 1/s, backing off to 8 s when the relay refuses. Starting or ending an emote is sent at the normal pace even while backing off. Off with the `shareMotion` pref and for remote signers (nip46): their emotes go out as an activity instead (`here:<x*10>:<z*10>` spot, kind `emote:<kind>`), played by main.ts `playEmoteClaims` through `applyMotion`.
- **Remote signers (NIP-46)** run on sky's own `nostr/remoteSigner.ts`, as obelisk-dex's bridge does: the login widget closes its paired signer when its modal unmounts, so sky builds a BunkerSigner on the same client key (no second `connect()`; on reload only when the pointer has a secret, then the account is checked). Every request has a deadline, the user's own requests (relay AUTH, posts) go before background ones (DM unwraps, read-state; one at a time), and a closed signer is rebuilt once. Never install the widget's `args.signer` for nip46.
- The group relay (public.obelisk.ar) only accepts events from whitelisted pubkeys after NIP-42 AUTH. Sky-only events are therefore signed with the player's own key (no throwaway session keys), and its per-pubkey rate limit is unknown: keep send rates conservative.

## World rules that are easy to break

- **Phones are played sideways.** Upright (`ui/orientation.ts` `PORTRAIT_PHONE`), a card asks to turn the phone and can go full screen and lock landscape; the manifest asks for landscape. Sideways (`(pointer: coarse) and (orientation: landscape) and (max-height: 540px)`): cards are a right side sheet, the chat and the side panel a left column, the menu a scrolling sheet, the look creator two columns, the login modal two columns of methods.
- **Phone layout** (`(max-width: 720px)` or a touch screen up to 1024 px): the bottom bar folds into the header's menu button (`#menu-btn`, `body.menu-open`, the same `.controls` buttons with `.ctl-label`s, plus About and Log out). The prompts (`#dock`: the voice call bar first, then seat, chat, someone near; at the bottom centre on desktop) gather over Jump. The joystick is 144 px (`input.ts` `R`). The person card is a bottom sheet with a sticky close button and a grip (drag down to close); a tap on the world closes it first. Every header pill is `--pill-h` tall; the status pill is the Live ⇄ History switch.
- **Chat panel and yards.** `place` (the yard you've settled in) drives the call bar and mark-read whether or not the chat is open. What the panel does on a place change is `ui/chatAuto.ts` `onPlaceChange` and the `chatOpen` pref (`auto` / `ask` (default: a "Press C" button) / `off`): a chat you opened yourself is never swapped or closed by walking.

- **Boot and intro** (`main.ts` boot block). `world.buildGround()` (procedural island, no models) and `cam.holdTopDown()` come first, and a preview loop renders that straight-down view behind `ui/loading.ts`'s SVG map (same framing: `topDownHeight` / `mapViewBox`, world −z up). Then the models load and `setGroups([])` builds the props, then the people. At `ready` the loading screen fades and `cam.playIntro()` swings down to your character or the home view. While the intro runs the camera bypasses OrbitControls and ignores director cuts. Any input or a `flyTo` finishes it quickly, and `Post.holdLevel` keeps "auto" quality from dropping during loading. Tilt-shift follows `cam.introProgress`.
- **Walking.** The NavGrid (0.5 cells) is for residents' pathfinding and coarse blocking. Fine collision is `world.solids` (axis-aligned boxes with a top): furniture you bump into but can jump onto (`top` low), posts you can't (`top` high). Don't use `blockAround` for small props; it blocks whole cells and makes invisible walls.
- **Ground height.** `World.groundAt` starts from the lawn as drawn: `island.ts` `terrainHeight` (the mesh is built from it; read back through `heightGrid`, 0.125 m bilinear). The lawn sinks `BUILDING_SINK` under every slot footprint so floors drawn at ~0 are never pierced; on top come the plaza paving (0.03), cobbled path cells (0.02), floors inside walkable rooms (0.006) and the raised ground below. Each body is lifted by its own `Character.soleLift` (measured standing idle: the clips crouch a little) while standing or walking, so soles rest on the ground. `World.groundAudit()` (console: `__sky.world().groundAudit()`) lists every standing person's sole height, their ground and the surface a ray hits under them.
- **Raised ground** (La Crypta's steps, mound and floor a storey up; the arched footbridges, `world/bridge.ts` `bridgeHeightAt`) is a landmark's `groundAt` (local, a smooth ramp with no ledges) or a bridge's arch, read through `world.groundAt`. The controller climbs and descends ground by the distance moved (`MAX_RAMP_SLOPE`), so keep ground free of ledges; furniture uses `solids`. The player controller stands on it (`floorAt`, a step down sticks to the slope); everyone else the world walks gets it as `Character.groundY` each frame (not while seated: seat heights are absolute; not the viewer: their `jumpY` already has it). Motion events carry no height: every screen derives it from the position.
- **Buildings you can enter** (HQ, café, La Crypta up its steps) keep their footprint blocked on the grid; the player may additionally walk their `interior.rooms` (`world.insideWalkable`). Doors open by distance to the player or a live mover; a mover inside has no grid path and walks straight. The follow camera gets a cutaway (roof hidden, walls see-through), first person does not. Indoor seats (`LandmarkSeat.indoor`, La Crypta's sofas) are for players only, offered from inside; NPCs never pick them (`nearestFreeSeat(…, npc)`), a live claim still can.
- **Landmarks** reserve slots before channels are assigned (`landmarks/index.ts` `LANDMARKS`, `reserveLandmarkSlots`). Each declares its real `footprint` and an optional `lawn` kept free of plaza lamps. The obelisk's stepped plinth is three `solids` (`obelisk.ts` `plinthSteps`, grid-blocked as a square, `PLINTH_HALF`). The parrilla is open at the sides; its brick asador (`ASADOR`: jambs, lintel, hood, chimney, one solid) has the brasero in its left quarter (`BRASERO`: where the wood burns, coals raked under the grate) and the grill over the rest (`GRILL`), benches on legs, cutlery, and its tile floor as `groundAt`. The café, parrilla, gym and Liberture house carry the shared "Bitcoin accepted here" plate (`signs.ts` `bitcoinSign`: one geometry, material and texture). The Liberture house (`landmarks/liberture.ts`) floats its six pillar orbs on an upright ring over the roof that swings like the nostr-wot graph (`ringYaw`), with emissive materials and additive halos and a single night-only point light; don't give each orb its own light (the light budget).
- **Voice channels are trees** (`world/ombu.ts`): an ombú with a campfire in front (`world/campfire.ts`) and log seats round it (seats with `tree: <channel>`, prop `marshmallow`: held out over the fire, eaten now and then) instead of a house. Campfire meshes animate, so `mergeStatic` skips anything under a `campfire` group. Their plot is open ground on the grid (`gridSlots` skips it; only the trunk is blocked), people in the call walk to free chairs (`gatherForCall`), and the plaza's three benches stand round the tree nearest the plaza (`placeBenches`, seats flagged `managed`), or at the plaza when there's none.
- **First person and you.** In first person your body draws nothing (it keeps its shadow) and your hands are drawn instead (`world/fpHands.ts`, hung on the camera). While you train or sit the camera steps out behind you, the body shows and the hands hide (`World.setSelfView`, `Cameraman.setWatching`); running laps stays in your eyes. The eye (`World.eyeOf`) stays over your body with its height above your feet low-passed, so the walk clip's head bob doesn't shake the view; `fpFeel` adds only a few millimetres of its own.
- **Benches and the mate.** Seats with the same `bench` id (plaza benches, La Crypta's sofas: three places each) share one mate once two people sit there: `world/mateRound.ts` (pure: the cebador sits in the middle, every pass is between neighbours) and `World.updateRounds`, which moves the one mate object from hand to hand halfway through a pass (`Character.reach`/`reachK`).
- **The gym and the track.** The gym is open 24 hours: its ceiling strips glow and its light is on by day and brighter at night (`gymLights`), the glass glows a little after dark. One channel's house becomes the gym (`world/gym.ts` `pickGymChannel`: a name like gym/fitness, La Crypta's first, else a sports channel; slot ≥ 2 wide). Its interior, floor ramp (`groundAt`), solids and machines (bench press, squat rack, curls, with `Character.heldBar`) are registered by `World.setGym`; enterable buildings are iterated by `World.enterables()`. The track's three lanes (`World.lanes`, `trackLap(site, n, lane)`) are stations of kind `run`: NPCs loop in theirs, your laps are run by the controller in `stepPlayer`.
- **Live and History.** The status pill switches between Live and History (`setHistory` in main.ts). History opens the panel under the village (`ui/history.ts`: spans of 24 h / 7 d / 30 d, the busiest stretches from `findEpisodes`, drag or click to replay) and sets `Player.history`: live messages are counted (`missed`) instead of pulling you back, and a replay that ends stays put.
- **Voice calls** (`voice/callRoom.ts`): a join is cancelled by any later join or leave (token), a dropped call reconnects with backoff (`RECONNECT_DELAYS`), a refused microphone leaves you listening (`micBlocked`), and walking out of the call's yard leaves after `AWAY_LEAVE_S` unless you press Stay.
- **Mentions** (`nostr/pings.ts`, obelisk-dex's rules): a reply to you or your name in the content or a `p` tag. Read once its channel is read past it or "Mark all read" (which also reads every channel). A pinged sign or its "@" arrow says who and where and opens the chat at the message; an @-chip in a bubble opens that person.
- **Zaps.** NIP-57 receipts on a message we hold, and the zap bot's kind 9 announcement (`⚡ @a sent N satoshis to @b`, `p` sender then recipient, `e` the message: `nostr/state.ts` `parseZapAnnouncement`) and obelisk-dex's zap marker (a kind 7 "⚡" reaction with `p`, `e`, `amount` msat and `bolt11`, posted after its wallet pays: `parseZapMarker`) all become a `WireZap`, never a ⚡ emoji; one zap arriving more than one way counts once (message|from|sats). The announcement stays in the chat (`WireMessage.zapNote`) but the bot doesn't walk over to say it: the zap flies from the sender to the recipient (`world/zapFlight.ts`) and bursts into coins.
- **Emotes** (`world/emotes.ts`, `ui/emoteMenu.ts`, G, 1–9 and 0): played while standing (`Character.setEmote`), ended by moving, jumping, sitting or training. `built` emotes (the groove dance, lotus, push-ups, jumping jacks) are made per body from key poses (`anim/exercises.ts` `EMOTE_CLIPS`, `PoseSpec.rise`/`sway`); `dance` stays Quaternius' `Dance_Loop` ("Dance 2"). Yours goes out in motion events (`e`, `es`); remote ones play when they stop. **Emotes keep one beat on every screen**, by the wall clock (`Date.now`, which devices keep within a fraction of a second): `sync: 'grid'` emotes (the dances, lotus, push-ups, jacks) play every body from one shared grid (`emoteAnchor` 0), `'leader'` ones (Sangreee) from the earliest start within `EMOTE_SYNC_M`; `Character.keepBeat` sets the clip time from `clipPhase` every frame. The menu keys are 1–9 then 0 (the tenth). "Sangreee..." (`sangre`, rounds of 7 s, the length of its sound, until you move) puts a knife in each fist and bleeds (`world/sangre.ts`, made and dropped by `Character` while it plays). Its materials are shared and flagged `userData.shared`, so `World.setBodyDrawn` (first person) leaves them alone and `Character.bodyDrawn` hides the props instead; in first person the camera steps out to watch it, as it does when you train or sit.
- **Sound settings.** Sound is the master switch; under it Ambient sounds (crickets), Footsteps, Emote music and Music at places each switch on their own. Music at places (`audio/placeMusic.ts`, `World.musicPlaces`, manifest `places`): cumbia at the parrilla, a guitar at every campfire, only the nearest place in reach plays (3.5 m parrilla, kept off the café 4.5 m away; 5.5 m campfire), crossfading between them, at the wall clock's point in the track. Browsers hold audio until a gesture they accept and phones suspend it again, so every key, click or lifted finger calls `Soundscape.wake` (main.ts `unlockSound`). Footsteps are yours only: `Character.onStep` fires when the other foot becomes the lower one, so they keep time with the walk and run clips.
- **Emote music** (`audio/emoteMusic.ts`, `audio/synthLoops.ts`): heard only near the dancers (HRTF panner, silent past 25 m); dancers within 6 m share one loop (the first one's), every loop starts on the wall-clock bar grid (the same bar on every screen, the beat the synced dances move to), at most two groups play. Dance and Dance 2 have their own music (`dance`, `dance2`). Training at the park or the gym plays `workout` for you alone: `World.dancers` adds only your own training (kind `'train'`, not running laps), so people passing don't hear it. An emote with a `sound` (`sangre.mp3`) plays it instead (`emoteSounds`), looped in rounds in time with the clip, people in step heard as one sound; it follows the Sound switch only (not Emote music), louder than the music (`SHOT_GAIN`) and loudest, unplaced, for the one doing it (`SELF_SHOT_GAIN`). Tracks from `public/sounds/manifest.json` when present, else synth loops. `docs/sounds.md` lists every sound and the Suno prompts, and says how to add, replace and tune them ("Managing the sounds": encode at −16 LUFS, masters in `_dl/sounds/`, a replaced file gets a new name because Cloudflare keeps `.mp3`s 4 h).
- **Nostriches** (`world/nostrich.ts`): built from boxes and animated in code. A `Flock` of four roams the island (they scatter from runners), and `nostrich` is a pet kind (no GLB; `Pet` builds it).
- **Characters.** When the world places someone (seat, station), call `resetDrive()` so a stale run or jump state doesn't override the pose. Seats put the person `SIT_SEAT_HEIGHT` below the seat. The badge and speech bubbles follow the head bone.
- **Live activities and movement.** People steered from another browser are *pinned* (`World.pinned`): `idleLife` and the Director's walks, conversations and despawns leave them alone.
  - A live claim (`World.syncClaims`, from `ActivityStore.live`) runs the person to the spot, or fades them across if far or pathless, then sits or trains them. An NPC on the spot is evicted. A claim beats movement.
  - Live movement (`World.applyMotion`) walks them at the player controller's speeds (`Character.pace`), fades them across when more than 4 m off, and goes stale after 75 s (`World.expireMotion`): they return to local life, or leave if they only appeared to move.
  - Spot ids are `station:<index>`, `seat:<x*10>:<z*10>` and `lane:<0..2>`, so moving a bench or reordering `CALISTHENICS_STATIONS` changes ids between builds. Gym machines are appended to `stations` after the park's, so park ids don't move when a gym appears.
  - NPC seat and station reservations go through `reserve`/`releasePending`, never `taken = 'pending:…'` directly.
- **Clothes and skin colour** (`people/people.ts` `tintable`): a garment's texture brightness is divided by its own mean linear luminance (`garmentLuma`), so it shows the chosen colour itself. Without that, trousers (mean ≈ 0.01) render black. Faces use the same dye as the hands at the skin tone, keeping a little of the painted texture (`SKIN_DYE`). Skin textures load with the look (`loadLook`) so they can be measured.
- **Lighting:** the hemisphere fill is what faces, pets' bellies and building sides turned from the sun get. `world/sky.test.ts` keeps day, dusk and night fill above a floor; don't drop it to darken a mood.
- **Exercise clips** are generated per body and grip height; hands are posed per grip (`OVER_BAR`, `ON_BAR`, `ON_PARALLEL`, `FLAT`) and the grip anchor is inside the curled fingers. Keep `exercises.test.ts` passing when changing poses.
- **Assets.** Cloudflare caches `/models/*` and `/assets/*` as immutable for a year: a changed file under the same URL keeps serving the old one (add `?v=`). The server's CSP must keep `blob:` in `connect-src` and `'wasm-unsafe-eval'` in `script-src`, or GLB textures and meshopt fail and bodies don't render.
- **Performance.** `__sky.perf()` (any build) reports one frame's draw calls and triangles (every post pass), lights on and the quality level. Keep it from regressing:
  - Channel houses are merged after building (`world/merge.ts` `mergeStatic`, one mesh per material); the roof (`name: 'roof'`) and `windows` stay separate. Anything you add to a house that moves, hides or changes on its own must be kept out of the merge too.
  - Landmarks and the gym are merged too: `findDynamic` runs their own hooks (update at a few times, night, door, inside, pulse) and keeps out every mesh that moved, hid, changed its shadow flag or geometry. Hooks put things back (a door opened then closed), so the poke calls `mark()` after each hook; without it doors get merged away. Something that only World code moves (not the landmark's own hooks) must be named and kept explicitly.
  - Phones: shadows at most 1024 and refreshed every 2nd–3rd frame; on "low" and still slow, "auto" renders fewer pixels (`lowScaleStep`, down to 60 %).
  - Point and spot lights are budgeted (`world/lightBudget.ts`): only the nearest few are visible, with constant counts so shaders don't recompile. A new lamp is picked up automatically; don't toggle `visible` on lights yourself. Every street lamp (`World.lantern`: round the plaza, at the park's corners, `CALISTHENICS_LAMPS`) has its own light, and they switch on together from early dusk (`lampLevel`), never half-lit.
  - People out of view are hidden and not posed (`Character.offscreen`). "Auto" quality starts by device and steps both ways (`world/quality.ts`); grass follows the effective level (`Post.onLevel`).
- **The frame loop never dies.** `main.ts` `loop` asks for the next frame first and catches a frame's throw (logged once per kind); `World.frame` always renders in a `finally`, after `Cameraman.guard` puts a non-finite camera back. A non-finite player position steps back to the last good one. A lost WebGL context (phones short of memory) is asked back (`webglcontextlost` → `preventDefault`), drawing pauses, and on restore `Post.stepDown` drops a quality level for good; after 5 s without it a toast offers a reload.
- **Ambient occlusion and the blur.** GTAO's normal pass would draw sprites and additive glows as opaque squares: `world/aoMask.ts` hides them from it. The tilt-shift is a jittered nine-tap blur; sparse taps turned bright points into dot grids.
- **Black flashes.** Resizing the canvas clears it, so the quality ladder (`Post.render`, `pendingLevel`) and window resizes (`World.frame`, `needsResize`) apply at the start of a frame, never after drawing. NaN/∞ from a glint or the AO is cut before the blurs (`SafeColor` after the scene and after GTAO) and in `Grade`.
- **Water shader:** GLSL `smoothstep(a, b, x)` needs a < b.

## Testing

Every change comes with tests next to the code (`*.test.ts`, `*.test.tsx`), and `npx tsc -p tsconfig.json` plus `npm test` must pass before a deploy. Visual changes also get a headless screenshot check. Use the playwright in `/root/obelisk-dex/node_modules` with `--use-angle=swiftshader`. It is slow, so allow minutes. The dev build exposes `window.__sky` (world, player, chat, controller, activity, motion) and `__skyDevLogin(hex)` for a throwaway key. Never log in with a real key in tests, and never post to a relay from tests. A logged-in test page shares movement by default: set `shareMotion: false` in the `obelisk-sky/prefs` localStorage entry first. To test remote people, feed signed events to `__sky.activity().ingest` / `__sky.motion().ingest` instead of publishing. Software rendering runs at about 1 fps (world time crawls), so poll for state rather than sleeping a fixed time; don't edit source files while a headless run is going (Vite reloads the page mid-run); and kill leftover `headless_shell` processes after a timed-out run.
